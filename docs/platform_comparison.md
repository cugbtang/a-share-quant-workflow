# 回测平台对比与选型（docs/platform_comparison.md）

个人做 A 股量化，回测平台直接决定了"回测结果是否可信"和"能否平滑过渡到实盘"。
下面对比 6 个主流选择，并给出针对本仓库作者背景（DevOps / Python / C++ / AI Infra）的推荐。

## 一、横向对比

| 平台 | 类型 | 数据质量/覆盖 | 涨跌停·停牌·复权 | 成本模型 | 实盘接入 | 语言 | 门槛/费用 | 适合人群 |
|---|---|---|---|---|---|---|---|---|
| **聚宽 JoinQuant** | 在线平台 | 高，A股全 | 内置正确 | 完善 | 支持（合作券商） | Python | 免费额度 + 会员 | 入门到进阶，想要"正确回测" |
| **米筐 RiceQuant** | 在线平台 | 高，A股/期货 | 内置正确 | 完善 | 支持（RQDelta/极速） | Python | 免费额度 + 会员 | 与聚宽类似，偏机构 |
| **优矿 Uqer** | 在线平台 | 中高 | 内置 | 一般 | 弱 | Python | 免费 | 研究/学习 |
| **QLib（微软）** | 本地框架 | 需自接数据 | 自行实现 | 自行实现 | 无（纯研究） | Python | 免费，需自己搭 | ML/因子研究，工程师 |
| **Backtrader** | 本地框架 | 需自接数据 | 需自配 | 可配佣金/滑点 | 无 | Python | 免费 | 想完全可控、写自定义逻辑 |
| **VectorBT** | 本地框架 | 需自接数据 | 需自配 | 可配 | 无 | Python | 免费 | 向量化高速回测、参数扫描 |

> 关键结论：**新手最该优先用聚宽/米筐**，因为它们已经正确处理了 A 股最坑的三件事——
> 涨跌停封板（涨停买不到、跌停卖不出）、停牌、前复权。自己用裸框架写错这几处的代价远高于平台费。

## 二、各平台简介

### 聚宽 / 米筐 / 优矿（在线平台）
- 优势：数据干净、回测引擎对 A 股规则建模正确、文档与社区成熟、可与合作券商实盘对接。
- 劣势：策略逻辑在平台沙箱里，本地工程化程度弱；高级功能收费。
- 用法：在本仓库 `backtest/event_study.py` 把逻辑验证清楚后，可平移到聚宽/米筐再跑一遍交叉验证。

### QLib（微软，本地）
- 优势：面向机器学习/因子研究，数据管理、因子计算、模型训练一条龙；完全本地、可接你熟悉的 Python/PyTorch。
- 劣势：**涨跌停/停牌/复权要自己实现**，数据要自己落库（正好复用本仓库 `data/`）；无内置实盘。
- 适合：你已经玩 MLX-LM、想上 lightgbm/Transformer 做因子合成时。

### Backtrader / VectorBT（本地框架）
- 优势：完全可控、可自定义任意规则、免费、可纳入你的 K8s 工程化流水线。
- 劣势：A 股规则（T+1、涨跌停、复权）要自己写；Backtrader 单进程偏慢，VectorBT 向量化快但学习曲线陡。
- 适合：回测逻辑已经跑通、想摆脱平台束缚、追求工程化/可复现时。

## 三、选型决策表

| 你的目标 | 推荐 | 理由 |
|---|---|---|
| 第一次跑通回测、求"结果可信" | **聚宽 / 米筐** | 内置 A 股规则正确，省去踩坑 |
| 验证本仓库已有策略 | 聚宽 / 米筐 | 与 `backtest/` 交叉验证 |
| ML/因子研究、想用 GPU/ML | **QLib** | 因子+模型一体，本地可控 |
| 完全自定义、纳 Pipeline | **Backtrader / VectorBT** | 工程化自由 |
| 最求速度、做参数扫描 | **VectorBT** | 向量化快 |

## 四、推荐路径（结合本仓库）

1. **起步**：在聚宽/米筐写第一个策略，确认回测可信。
2. **本地化**：把逻辑搬回本仓库 `backtest/`，用 `data/` 落库的数据在 Backtrader/VectorBT 复现，验证一致性。
3. **进阶**：用 QLib 做因子/ML 合成，复用 `data/` 的数据层。
4. **实盘**：通过迅游 QMT（见 `live/`）接程序化下单，而非平台自带实盘（更可控、更便宜）。

## 五、注意事项

- 任何平台回测都只是"近似"，实盘还有滑点、流动性、柜台延迟，务必先模拟盘。
- 在线平台免费额度有限，大样本/高频回测可能需付费或本地化。
- 因子有效性会衰减，别迷信平台里"历史收益翻倍"的策略。

> ⚠️ 本文为工具选型参考，不构成投资建议。平台费率/规则以官方最新公告为准。
